Polynomial-Modulated Galois LFSR PRNG

A configurable pseudo-random number generator based on a Galois LFSR architecture with dynamic primitive-polynomial selection, functional verification, and ASIC-oriented logic synthesis.

PROJECT OVERVIEW

Configurable pseudo-random sequence generation

This project explores a Galois LFSR-based pseudo-random number generator with a polynomial-selection mechanism that dynamically switches between multiple primitive polynomials.

The design was implemented at RTL level, functionally verified, statistically evaluated, and synthesized using the Sky130 standard-cell technology library.

IMPLEMENTATIONS 4 / 8 / 16-bit
PROCESS Sky130 130 nm
MAX FMAX 1.0 GHz
SYNTHESIS Cadence Genus
01 — ARCHITECTURE

Proposed PRNG Architecture

The proposed PRNG combines a Galois LFSR with primitive-polynomial selection logic consisting of a comparator, counter, and multiplexer. When the generated LFSR sequence returns to the initial seed, the comparator detects the match and advances the counter to select a different primitive polynomial.

02 — ALGORITHM

Polynomial Switching Algorithm

The algorithm starts by loading the initial seed and selecting a primitive polynomial. The LFSR then generates a sequence until its output returns to the seed value. When a match is detected, the counter increments and the multiplexer selects a new primitive polynomial before sequence generation continues.

03 — RTL DESIGN

Modular RTL Implementation

The design was implemented using modular RTL blocks for the Galois LFSR, primitive-polynomial generator, comparator, counter, and top-level integration logic. The architecture was designed to support different LFSR widths by changing the primitive-polynomial set and register width.

04 — FUNCTIONAL VERIFICATION

Sequence & Polynomial Switching Verification

Functional verification checked reset behavior, generated output sequences, seed-match detection, counter operation, and primitive-polynomial switching.

05 — LOGIC SYNTHESIS

ASIC-Oriented Logic Synthesis

The RTL implementations were synthesized using Cadence Genus with the Sky130 standard-cell technology library. Timing constraints were adjusted according to design complexity to determine practical operating frequencies.

DESIGN 8-bit
TARGET FREQUENCY 0.8 GHz

06 — PPA & TIMING RESULTS

Performance Comparison

Increasing the LFSR width increases the number of registers and associated selection logic. As a result, area and power consumption increase, while the achievable maximum operating frequency decreases.

Design Fmax Power Area
4-bit 1.0 GHz 1.14 mW 926.517 µm²
8-bit 0.8 GHz 1.906 mW 1767 µm²
16-bit 0.7 GHz 3.04 mW 3258 µm²
Engineering Observation

Larger LFSR widths require additional sequential and selection logic, increasing area and power while reducing maximum operating frequency.
