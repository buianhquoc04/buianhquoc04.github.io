Digital IC Design & Layout – 45 nm PDK

Transistor-level schematic design, custom physical layout, and physical verification of selected digital cells using Cadence Virtuoso and Cadence PVS.

PROJECT OVERVIEW

From transistor-level schematic to verified physical layout

This project focuses on custom IC implementation using a 45 nm process design kit. The selected work presented here includes a four-stage tapered buffer and a custom transistor-level D flip-flop.

For both cells, the design flow consisted of schematic design, custom physical layout, Design Rule Checking (DRC), and Layout Versus Schematic (LVS) verification.

DESIGN 01

Multi-Stage Tapered Buffer

✓ DRC CLEAN ✓ LVS MATCHED

A four-stage tapered buffer was designed at transistor level with progressively increased device multiplicity (1× → 3× → 9× → 30×) to increase output-driving capability. A three-row physical structure and multi-layer routing strategy were used during custom layout implementation.

01

Schematic Design

Four-stage tapered architecture with progressively increased transistor multiplicity toward the output stage.

02

Physical Layout

Custom physical implementation showing device organization, power distribution, and signal routing across the designed buffer stages.

03

Physical Verification

Cadence PVS was used for Design Rule Checking and Layout Versus Schematic verification.

DESIGN 02

Custom D Flip-Flop

✓ DRC CLEAN ✓ LVS MATCHED

A custom D flip-flop was implemented at transistor level and translated into a compact physical layout. Device placement and routing were arranged with emphasis on source/drain sharing and physical layout efficiency.

01

Schematic Design

Transistor-level implementation of the custom D flip-flop used as the reference circuit for physical layout development.

02

Physical Layout

Custom device placement and multi-layer routing were implemented in Cadence Virtuoso.

03

Physical Verification

The completed layout was verified using Cadence PVS to ensure compliance with design rules and connectivity consistency with the original schematic.
