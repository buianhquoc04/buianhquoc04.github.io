MEMORY CIRCUIT DESIGN

TCAM Memory Circuit Design

Transistor-level design and functional verification of a TCAM cell and an 8×8 TCAM array, including write, precharge, and parallel search/compare operations.

TCAM 8×8 Array Transistor-Level Design Functional Simulation Content-Addressable Memory
PROJECT CONTEXT

Team Memory-Circuit Project

This work was completed as part of a team project covering SRAM and TCAM memory circuits.

My primary contribution focused on TCAM circuit design and functional verification. I also reviewed the operating principles of the 6T SRAM cell as background for understanding transistor-level memory structures.

PRIMARY CONTRIBUTION TCAM Cell & 8×8 TCAM Design / Verification
01 — TCAM CELL

Transistor-Level TCAM Architecture

The TCAM cell combines a core storage cell, a mask cell, and comparison circuitry. In addition to storing binary values, the mask mechanism allows the cell to represent the ternary don't-care state used in content-based searching.

02 — OPERATION

Write, Precharge & Compare Sequence

TCAM operation is divided into three main stages: writing the stored value, precharging the Match Line, and comparing the search data against the stored data. Before comparison, the Match Line is precharged high. A matching cell keeps the Match Line high, while a mismatch activates a discharge path toward ground.

WRITE Store Core / Mask
PRECHARGE HL → High
COMPARE Match / Miss
03 — FUNCTIONAL CASES

Match, Miss & Ternary Behavior

Multiple functional cases were evaluated to verify normal MATCH and MISS conditions together with the ternary behaviors enabled by the mask cell.

MATCH HL = 1
MISS HL = 0
TERNARY 0 / 1 / X
04 — ARRAY DESIGN

8×8 TCAM Array

The verified TCAM cell architecture was extended into an 8×8 array to evaluate multi-row storage and parallel content searching. Each row provides a Match Line that indicates whether the stored word matches the applied search data.

05 — WRITE VERIFICATION

Multi-Row Data Storage

Functional simulation was performed by writing different data patterns into selected TCAM rows. The wordline and bitline control signals were sequenced to program the core and mask cells before entering the search phase.

ROW 1 0000 0001
ROW 3 0000 0011
ROW 5 1111 1110
ROW 7 1111 1100
06 — SEARCH VERIFICATION

Parallel Search & Compare

After writing the selected rows, the Match Lines were precharged and search patterns were applied to the entire array. During a successful search, the matching row retains its Match Line at logic high while the mismatched rows discharge to logic low.

ROW 3 SEARCH HL[3] = MATCH
ROW 5 SEARCH HL[5] = MATCH
NON-STORED DATA No Match
Verification Result

The 8×8 TCAM successfully identified stored search patterns by preserving the Match Line of the corresponding row while discharging mismatched rows.

FUTURE WORK

Match-Line Sensing & Priority Encoding

Further development could integrate a Match-Line Sense Amplifier to detect small Match-Line voltage differences more quickly in larger arrays.

A priority encoder could also be added to convert multiple Match-Line outputs into a compact binary address when more than one row matches the search pattern.
